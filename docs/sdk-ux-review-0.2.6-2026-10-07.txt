해결 확인 1. DOCX/HWPX preset 한 번 Undo 및 Redo

DOCX
본문 '한국어' 선택에서 원래 10pt/왼쪽 정렬을 확인했다.
보고서 제목 preset 적용 후 16pt/가운데 정렬로 바뀌었다.
Undo 한 번으로 10pt/왼쪽 정렬, Redo 한 번으로 16pt/가운데 정렬이 됐다.
마지막에 Undo로 원래 상태를 복구했다.

HWPX
본문 '한국어' 선택에서 원래 10pt/양쪽 정렬을 확인했다.
preset 적용 후 16pt/가운데 정렬, Undo 한 번 후 10pt/양쪽 정렬,
Redo 한 번 후 16pt/가운데 정렬, 마지막 Undo 후 원래 상태가 됐다.
HWPX는 명령 직후 툴바 상태가 비동기로 갱신되므로 목표 크기와 정렬이 반영될 때까지
기다린 뒤 판정했다. 즉시 읽은 중간 상태를 결함으로 집계하지 않았다.

코드
DocumentEditor.applyPreset이 엔진의 executePreset을 사용한다.
DOCX는 계획한 변경을 한 canonical transaction으로 반영한다.
HWPX는 JS 빌드 플러그인의 outer SnapshotCommand로 내부 서식 명령 이력을 묶는다.
권한/문서 세션 확인과 명령 검증 경로도 읽었다.
네이티브 엔진에 실행 중 예외를 강제로 주입하는 실패/rollback 시험까지 직접 수행한 것은 아니다.
외부 엔진의 executePreset 미지원 시에는 여전히 순차 fallback을 사용한다.

증거: 02-docx-preset-one-undo.png, 06-hwpx-preset-one-undo.png
