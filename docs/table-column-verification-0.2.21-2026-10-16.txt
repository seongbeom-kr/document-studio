Document Studio 0.2.21 — 표 열 편집 구현·검증
검증일: 2026-10-16

완료한 범위
- DOCX·HWPX의 선택한 본문 표 한 열에 숫자 쉼표 또는 문자열 치환.
- 표 설명·열 제목·행열 좌표, 변경 전후 값, 제외 셀과 사유를 미리 표시.
- 숫자 열을 명시해야 쉼표 처리. 식별자/날짜 표제와 값, 앞자리 0, 긴 숫자 번호 보호.
- 병합된 제목은 해당 열 전체 제외. 병합 셀·다중 문단·중첩·특수 요소·혼합 서식 제외.
- 동일한 readTable → previewTableColumn → applyTableColumn 경로를 UI와 에이전트가 사용.
- 미리보기 이후 문서·세션·revision·선택 변경과 읽기 전용 권한을 검사.
- 적용 중 입력 차단, native transaction/snapshot, 한 번 Undo/Redo.
- 시도한 preview 재사용 금지와 operationId 결과 재전달. 알 수 없는 결과를 자동 재시도하지 않음.
- 실패 효과 none / rolled-back / unknown. 저장은 별도이며 성공 영수증에 committed=false.
- React 외 DOM 어댑터에도 같은 세 메서드를 제공.

개발 중 발견해 수정한 사항
- HWPX의 deferred 짧은 치환 API는 긴 문자열에 사용할 수 없었다. 전체 native 셀 삽입/삭제를
  한 snapshot 명령 안에서 수행하도록 변경하고 긴 한글·이모지 치환을 확인했다.
- HWPX 검색 결과의 빈 cellPath 배열 때문에 셀 서식 명령이 거절되는 경로를 수정했다.
- HWPX 두 번째 셀 쓰기를 강제로 실패시켜 첫 셀까지 원복되고 이전 Undo 기록도 유지됨을 확인했다.
- 엔진의 일반 예외 또는 적용 후 상태 조회 실패도 unknown으로 보고하고 재실행하지 않도록 보강했다.

검증 한계·후속 범위
- 실제 인증된 샌드박스 SSO/BFF와 새 표 기능의 실제 LLM 대화는 이번에 검증하지 않았다.
  이 세션의 보호된 origin 브라우저 접근 거절을 다른 접근 경로로 우회하지 않았다.
- 모든 업무 문서, 실제 한컴 한글에서의 재열기, 물리 Windows IME 검증은 별도이다.
- 헤더 없는 일반 숫자 사번 등의 의미를 자동 판별한다고 보장하지 않는다.
  열 의미가 불명확하면 unknown을 유지하고 사람이 변경 미리보기를 확인해야 한다.
- 기존 표의 합계·계산·복잡한 구조 변경은 후속 단계이다.
- REA 자료의 기능 분류만 참고했으며 실행 파일 코드·이미지·기관 서식을 배포물에 복사하지 않았다.
