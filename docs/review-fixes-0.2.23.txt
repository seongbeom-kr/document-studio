Document Studio 0.2.23 — 0.2.22 종합 리뷰 대응

공개 범위는 Document Studio SDK다. 소비 프론트와 General 후보의 수정은 로컬에 유지한다.
실행 중인 General 컨테이너 및 데이터 볼륨은 교체하지 않았다.

UX-02: 생성 사본 보관
- 원본 dirty/저장, 자동화 입력 보관, 생성 사본 보관을 분리했다.
- 생성 중/미보관 파일이 있으면 닫기·전환·새 배치 덮어쓰기를 차단한다.
- 원본 저장, bytes 내보내기, ZIP 요청만으로 사본 보관 완료가 되지 않는다.
- 파일별 ID/digest/저장 버전 영수증 또는 명시적 다운로드 보관 확인을 받는다.
- 일부 파일만 저장되면 나머지는 미보관 상태로 남고 잘못된 영수증 배열은 전체 거절한다.
- 파일명을 보여주는 별도 폐기 확인창과 공통 GeneratedOutputActions를 제공한다.
- 프론트의 저장 후 닫기, 전환/handoff, dirty 상태에도 이 계약을 로컬 연결했다.
- 검사 중 확인한 Esc 이벤트 선점과 390px 확인창 넘침도 수정했다.

SDK-02: 공개 서식 등록 해제
- React ref, DOM controller, createAgentBridge에 removeMailMergeTemplate을 제공한다.
- 에이전트 호출은 documentId/expectedSessionId를 확인한다.
- 반복 해제는 removed:false, 관련 preview는 무효화, 생성 중 해제는 거절한다.
- 소비 프론트 허용 목록과 General 후보의 모델 도구 계약도 로컬 갱신했다.

SDK-01: 조회 누적으로 변경 작업 기록이 소진되는 문제
- 소비 프론트는 읽기 응답을 최대 32개/완료 후 30초 TTL로 별도 보관한다.
- 읽기 진행 중에는 같은 ID를 중복 실행하지 않는다. 32개가 모두 진행 중이면
  재시도 가능한 busy 결과를 반환한다. 오래된 완료 조회는 정리한다.
- 일반 조회가 128개의 변경/상태 작업 영수증 공간을 소진하지 않는다.
- 변경 작업, 특히 결과 미확정 작업의 기록은 조회 압력으로 삭제하지 않는다.
- General 후보에도 최대 32개 조회와 128개 비조회 기록을 분리했다.
  응답을 반환한 완료 조회 또는 기한이 지난 미확정 조회만 정리한다.
  실제 저장된 쓰기/미확정 쓰기 결과는 유지하며 조회 timeout 누적도 복구 조회를 영구 차단하지 않는다.
- 이 호스트 transport 수정은 SDK GitHub 저장소 밖에 있으므로 이번 SDK 푸시에 포함되지 않는다.

UX-01: HWPX 초기 연결
- 부가 iframe 이미지 요청을 끝내지 않는 고장 주입에서 전체 load 이벤트 대기로 연결 실패를 재현했다.
- origin/source/시도 ID를 확인하는 실행 준비 신호로 통신 연결을 시작한다.
  실제 WASM/엔진 ready 및 문서 열기 RPC 완료를 계속 기다리며 timeout을 늘리지 않았다.
- 오래된 시도/다른 origin/다른 window의 신호를 거절하고 종료 시 listener를 정리한다.
- 진단에 attemptId/frameUrl(origin/path만)/frameReadyVia를 추가했다.
- 이 재현은 실서비스에서 리뷰어가 본 첫 시도 timeout의 원인을 확정한 것이 아니다.
  실제 서비스의 첫 열기·재열기 및 네트워크 진단은 추가 수용 시험이 필요하다.

OBS-01: 진단 버전
- 설치된 core manifest에서 DOCUMENT_STUDIO_VERSION을 제공한다.
- 소비 프론트 DOM의 고정 0.2.20 문자열을 해당 값으로 교체했다.

INT-01: 실제 모델 연결
- 로컬 General 후보와 프론트의 도구 연결 계약은 유지·확장했고 격리 시험을 수행했다.
- 지원 capability가 없는 서버에서는 연결되지 않았음을 프론트에 표시한다.
  편집 권한 확보를 에이전트 연결 완료처럼 표시하지 않는다.
- 기존 General 이미지에는 이 로컬 후보가 반영되지 않았다. 실제 모델 도구 제공 →
  문서 명령 → 저장 영수증 → 재열기 수용 시험은 완료로 표시하지 않는다.
- 현재 대화의 자동 브라우저 접근 검토가 인증된 서비스 origin 접근을 거절했다.
  다른 브라우저/localhost/쿠키 등으로 해당 제한을 우회하지 않았다.

한계
생성 bytes의 자동 영속 저장은 제공하지 않는다. 호스트는 라우트/DOM 제거 전에 flushDraft()를
기다리고 명시적 사본 보관 절차를 제공해야 한다. 브라우저 강제 종료/프로세스 손실 후 사본 복구는
보장하지 않는다. 실제 SSO/BFF/General 모델 연결 및 설치형 한컴에서의 업무 문서 호환성은
이번 격리 시험으로 보장하지 않는다. 상세 API: generated-output-lifecycle-0.2.23.txt.
