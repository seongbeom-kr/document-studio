# 기능 지원과 적용 범위

2026-10-05 로컬 검증을 기준으로 하며, 2026-10-07의 0.2.7 SDK·UX 리뷰 대응을 반영했습니다. 공통 SDK·UI 기능과 고정 엔진의 확장 UI를 구분합니다. 실행 가능 여부는 `getState().commands`와 `agent.listCommands()`에서 현재 선택에 대해 확인합니다. 엔진은 RHWP core/editor 0.8.6, EigenPal core/react 2.25.0입니다.

`readDocument()`의 paragraph id는 조회용입니다. 임의 좌표 쓰기는 제공하지 않으며 `search()`의 opaque match id와 같은 revision으로 `select`/`replace`합니다. 새 검색이나 편집으로 예전 결과가 만료될 수 있습니다. DOCX 객체 안 텍스트와 HWPX 수식·깊은 중첩 셀 자동 치환은 지원하지 않습니다. 전체 치환은 변경 전 모든 대상의 실행 가능성을 검사합니다. DOCX 본문·표의 모두 바꾸기는 공개 automation API의 원자적 batch로 실행해 Undo/Redo 한 단계로 보존합니다. 본문 외 영역은 모두 바꾸기를 명시적으로 거부하고 개별 치환을 사용합니다.

표·그림 삽입의 선택 문맥과 native 고급 도구는 형식마다 다릅니다. 모든 고급 메뉴와 실제 업무 파일의 호환성을 검사한 상태는 아닙니다. 테스트한 기능과 연결만 된 기능을 같은 품질 보증으로 표시하지 않습니다.

0.2.7은 업무 자동화의 기능별 세션 입력 보존, 명시적 예제 초기화, 새 문서 생성 실패 재시도와 로딩 중 문서/권한 변경 보호를 추가합니다. 샌드박스 호스트에는 생성 파일 업로드·목록 갱신·기존 문서 저장/잠금 해제·새 파일 열기를 연결했습니다. DOCX 그림은 글자처럼 같은 줄에 배치합니다. 표 셀의 그림 삽입은 고정 엔진이 허용하는 텍스트 세그먼트 경계(문단 처음/끝 포함)에서 지원하며 임의 run 중간은 거절될 수 있습니다.

댓글 작성·변경 추적·실시간 협업·상용 PDF converter/editor-api는 채택하지 않았습니다. PDF 텍스트 읽기, 실제 XLSX 파일 병합/편집, HWP·PPTX 편집, 기관별 native 단축키와 Windows 배치 작업은 후속 범위입니다.

0.2.18부터 표준 build는 다섯 SDK 패키지입니다. React 컴포넌트 외에 `@document-studio/browser`의 DOM API로 일반 JavaScript·Vue 호스트에 연결할 수 있습니다. 내부 렌더링에는 React를 사용합니다. 문서 목록·라우팅·인증·서버 저장·LLM transport는 소비 앱이 소유합니다. playground는 개발 예제이며 별도 제품 서버를 요구하지 않습니다.

0.2.8은 HWPX 내부 입력 차단, 중첩 가능한 `acquireInputLock()`과 편집 세션별 잠금 수명을 추가합니다. 샌드박스는 마지막 저장부터 lease 해제·문서 전환까지 잠금을 유지하고, 이전 문서의 늦은 저장 콜백이 현재 미저장 상태를 바꾸지 않도록 검증합니다. 검증 범위와 재현 시험은 [0.2.8 수정 기록](review-fixes-0.2.8-2026-10-07.txt)에 있습니다.

0.2.18은 공통 controller와 에이전트 브리지를 core에서 제공합니다. DOM의 문서 교체·종료는 초안 보관을 기다리고 실패하면 기존 편집기를 유지합니다. HWPX의 페이지 내부 짧은 입력도 revision과 미저장 상태에 즉시 반영하도록 수정했습니다. 자동화 transport나 UI 영역 배치 API를 추가한 버전은 아닙니다. [0.2.18 검증 기록](review-fixes-0.2.18-2026-10-15.txt)을 참고하세요.

0.2.19는 `ui.containers`/`ui.theme`으로 툴바·상태·편집/자동화 도구를 호스트의 UI에 배치하며, React `slots.toolbar`/`slots.statusBar`로 기본 영역을 확장·교체합니다. 영역 이동과 테마 변경은 문서 세션과 도구 입력을 유지합니다.

0.2.20은 20개 업무 편의기능에 공통 입력 검증·미리보기와 에이전트 dispatcher를 제공합니다. 현재 문서에는 선택 범위를 확인한 뒤 텍스트로 적용하며, 표·보고서 구조를 유지하는 새 문서는 호스트가 제공한 engine factory로 생성합니다. 그림 결과의 에이전트 삽입과 명찰·명패의 인쇄 배치는 지원하지 않습니다. 실제 LLM 연결·인증·편집권·명령 전달은 호스트의 책임이며 SDK만 설치하면 연결되는 기능이 아닙니다.

HWPX의 지연 페이지 배치 계산을 새 편집으로 세지 않도록 구분해, 저장 후 불필요한 복구 초안이 다시 생기는 경합도 수정했습니다. 실제 입력과 알 수 없는 변경 신호는 계속 추적합니다. [0.2.19 검증 기록](review-fixes-0.2.19-2026-10-15.txt)에 초기 실패·원인·최종 재검증을 구분해 두었습니다.
