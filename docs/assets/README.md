# README assets

- `banner.svg`: original vector artwork created for Document Studio. It contains no embedded fonts, remote images, scripts, or third-party branding.
- `editor-hwpx.png`, `editor-docx.png`: actual Document Studio 0.2.23 screenshots, captured at a 1440 × 900 browser viewport using the local SDK harness. The visible report was generated specifically for these screenshots. All names and values are synthetic.

The HWPX screenshot shows an unapplied table-column preview: two numeric cells would change, while the header, a leading-zero identifier, and an eight-digit date are excluded. The DOCX screenshot shows the common paragraph panel. Neither image represents a production host or an authenticated agent connection.
