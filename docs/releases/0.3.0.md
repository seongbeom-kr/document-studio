# Document Studio 0.3.0

2026-10-31 · 소스 및 tarball 릴리즈

`0.3.0-beta.9`에서 베타 표기를 제거한 첫 `0.3.0` 배포 버전입니다. 이번 승격은 패키지 버전과 배포 안내를 정리하며 편집 기능과 공개 API 구현을 변경하지 않습니다.

## 패키지

다음 다섯 패키지를 같은 버전으로 제공합니다.

| 패키지                         | 역할                                                                |
| ------------------------------ | ------------------------------------------------------------------- |
| `@document-studio/core`        | 공통 문서·편집·저장 계약과 에이전트 API                             |
| `@document-studio/react`       | React 편집기 UI                                                     |
| `@document-studio/engine-docx` | DOCX 편집 엔진 연결                                                 |
| `@document-studio/engine-rhwp` | HWPX·지원되는 HWP 문서의 엔진 연결과 정적 런타임                    |
| `@document-studio/browser`     | 일반 JavaScript·Vue 호스트용 DOM 연결. 내부에서 React 편집기를 사용 |

React 호스트는 앞의 네 패키지를 사용합니다. DOM 연결이 필요한 호스트는 `browser`도 설치합니다. `browser`는 별도 브라우저 프로그램이나 서버가 아닙니다.

## 설치와 갱신

[패키지 빌드·소비 안내](../release-guide.md)에 따라 같은 소스에서 tarball을 생성하고 설치합니다. npm registry에 공개 게시됐다는 뜻은 아닙니다.

소비 앱은 SDK 패키지와 HWPX 정적 자산·글꼴을 함께 갱신해야 합니다. SDK 저장소의 새 커밋만으로 소비 앱에 설치된 버전이 바뀌지는 않습니다. 앱의 잠금 파일과 패키지 해시를 갱신하고 앱의 기존 빌드·배포 절차로 반영합니다. 별도 SDK 서버는 필요하지 않습니다.

## 지원 범위

편집·저장·초안 복구와 에이전트 API의 계약은 [통합 안내](../integration.md), 문서 형식별 기능과 제한은 [지원 기능](../feature-support.md)에 따릅니다. 호스트가 사용자 권한, 문서 식별자, 저장소 버전과 영속 저장을 관리합니다.

원본 글꼴, 복잡한 업무 문서, 한컴·Word 재열기, 실제 호스트의 저장 계약은 도입 환경에서 확인해야 합니다. 버전 승격을 모든 문서의 동일 조판이나 모든 에이전트 요청의 성공 보장으로 해석하지 않습니다. `0.x`의 API는 발전 과정에서 변경될 수 있으며 `1.0.0`의 호환성 정책 확정과 구분합니다.

프로젝트 라이선스는 Apache-2.0입니다. 포함된 엔진·글꼴의 라이선스와 고지는 기존과 같이 보존하며 [라이선스 안내](../licensing.md)를 따릅니다.
