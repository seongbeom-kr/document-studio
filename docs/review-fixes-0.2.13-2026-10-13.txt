P2 — 중첩 표 검사
inspect.ts의 descendant 속성 조회를 현재 셀의 직접 소유 속성 조회로 바꾼다.
DOCX gridSpan/vMerge는 직속 tcPr에서, HWPX cellSpan/cellAddr는 직속 tc에서 읽는다.
DOCX tblGrid의 열 수와 trPr의 gridBefore/gridAfter, HWPX의 직접 셀 주소를 반영한다.
잘못된 크기·주소·병합 값은 오류로 거절한다. 바깥 표의 속성과 안쪽 표의 속성을
상속시키지 않으며 중첩 표는 별도 snapshot 주소로 계속 반환한다.

셀 텍스트 정책도 명시한다. 현재 셀이 소유한 text run을 문서 순서로 연결하고,
중첩 tbl 아래 텍스트를 제외한다. 안쪽 표 내용은 그 표의 셀에서 반환하므로
같은 문자열을 바깥/안쪽에 중복해서 반환하지 않는다. 기존 2,000자 제한을 유지한다.
DOCX 세로 병합은 restart/continue 원본 상태로 반환하며 전체 rowSpan 추론은 제공하지 않는다.

회귀 시험은 부모 1열/자식 2열 병합, 부모 자체 병합, 3단 중첩, 부모·자식의
세로 병합 분리, 셀 주소 분리, grid의 생략된 열, 잘못된 span과 긴 셀 텍스트를 포함한다.
DOCX와 HWPX XML을 실제 브라우저 DOMParser에서 검사한다. 자체 제작한 DOCX 중첩
표는 실제 DOCX 엔진에서 열고 공개 agent.inspect와 내보낸 XML을 함께 대조한다.
이 시험이 HWPX의 모든 중첩 표를 native 편집·저장했다는 뜻은 아니다.

P3 — 표시 이름 검색
표시 이름과 내부 이름, 기능 그룹 이름을 검색 기준으로 사용한다.
명찰/명패/내용 초안 검색에서 화면에 표시하는 기능을 찾는다.
검색 결과 수에 현재 선택을 더하지 않고, 맞지 않는 선택은 '현재 선택 · 입력 유지'
그룹에 별도로 둔다. 없는 검색어는 결과 없음과 선택·입력 유지의 이유를 안내한다.
검색어 변경/지우기와 기능 왕복 전환에서 원본 입력이 유지되는 것을 검사한다.

P3 — 접힌 결과의 빈 열
구조 작업은 원본과 표·카드·그림 미리보기를 같은 grid에 배치한다.
평문 결과 disclosure는 grid 밖의 별도 한 줄 영역으로 옮긴다.
좁은 패널은 한 열로 배치하며 긴 구조 미리보기는 내부에서 스크롤할 수 있다.
계산 도구의 원본/텍스트 결과 두 열과 결과 수동 편집을 유지한다.
1366px와 480px 브라우저 시험에서 빈 열 제거, 미리보기 위치, disclosure 열기/닫기,
표·명찰·차트 전환, 계산 결과 편집을 검사한다.
