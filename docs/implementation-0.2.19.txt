Document Studio 0.2.19 UI 구성 계획

0.2.18 검증·커밋 후 진행한다. 프론트의 원격 브랜치와 기준 커밋은 변경하지 않는다.

공개 계약
- ui.containers로 toolbar/statusBar/tools를 호스트 DOM 영역에 배치한다.
  tools에는 문단·표·그림·검색·보고서·업무 자동화가 포함된다.
- ui.theme은 SDK와 외부 배치 영역에 같은 색·글꼴·모서리 토큰을 적용한다.
- React slots.toolbar/statusBar는 기본 UI와 guarded 명령/패널 열기 함수를 받아
  앱의 버튼/상태 컴포넌트로 확장하거나 교체한다.
- browser.update는 같은 ui 계약을 사용한다. React 슬롯 함수는 DOM API에서 제외한다.
- 오류·저장 경고·초안 복구·확인창은 슬롯으로 숨기지 않는다.

수명·검증
영역 이동은 SDK가 소유한 DOM만 옮기고 호스트 자식을 보존한다. 문서 엔진과
도구 폼 상태를 재마운트하지 않는다. 기존 입력 잠금·저장·대상 검사를 유지한다.
잘못된 DOM 대상은 거절하며 React 커스텀 슬롯 오류는 기본 UI로 복구해 표시한다.
외부 패널에서도 단축키·읽기 전용·실패 메시지가 작동해야 한다.

실제 엔진 DOCX/HWPX × Chrome/Edge에서 분리 배치·호스트 재렌더·테마 변경·패널
이동·입력 보존·저장/재열기·읽기 전용·실패·다중 인스턴스·종료 정리를 검사한다.
모바일/낮은 창의 넘침·포커스·기존 도킹 패널 회귀도 검사한다.
프론트는 호스트 소유의 툴바/상태 영역에 연결하고 기존 저장/lease 흐름을 보존한다.
완료 후 SDK만 커밋·푸시하며 프론트는 로컬 변경만 유지한다.
