Document Studio 0.2.22 구현 범위

1. 빠른 작업
   기준일을 명시한 오늘/어제/내일, 주간(월~금/월~일), 월간/연간 날짜 미리보기.
   기존 보고서/호스트 서식을 빠르게 선택하고 같은 guarded SDK 경로로 적용.
   문서·세션·revision·선택·권한 검증, operationId 재전달, 저장 별도.
2. 표 열 가공
   0.2.21의 private preview/atomic apply 경로에 prefix/suffix/trim/collapseSpaces 추가.
   기존 식별자·날짜·병합/복잡한 셀 보호와 Undo 단위 유지.
3. 사용자 서식과 메일머지
   DOCX/HWPX 파일 또는 현재 편집본 등록, {{필드}} 목록과 위치 확인.
   CSV/TSV 열 매핑, 빈 값과 누락/지원 불가 위치/파일명 중복 사전 확인.
   검증된 서식의 텍스트 필드만 바꾼 독립 사본을 한정된 수량으로 생성.
   원본·현재 문서에 쓰지 않고 전체 성공 후만 ZIP/SDK 결과 공개.
   데이터와 매핑은 기존 호스트 자동화 초안 정책으로 보관. 등록한 파일은 세션 메모리이며
   재열기 때 다시 선택해야 함을 표시. 출력 생성과 다운로드 요청과 서버 저장은 구분.
4. 검증·통합
   순수 함수 경계 테스트, DOCX/HWPX 실제 엔진 E2E, 손상/누락/취소/재전달/권한 경합,
   저장·재열기·미디어/서식 보존, 좁은 화면, 소비 앱, 라이선스/audit.
   로컬 프론트 SDK 교체와 settings 동시 실행. General transport는 로컬 후보에 연결.
   SDK만 seongbeom-kr로 커밋/푸시. 프론트/General 원격 푸시·기존 컨테이너 교체 없음.

이번 범위 밖: 기존 표 합계/계산/구조 변환, 목차·메모 객체, XLSX/PPTX 편집.
범피스 보고서의 기능 분류와 관찰 결과를 참고하며 실행 파일 코드/기관 양식은 사용하지 않음.
