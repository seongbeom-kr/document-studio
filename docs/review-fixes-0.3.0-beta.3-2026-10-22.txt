Document Studio 0.3.0-beta.3 — 대상 보호 및 복구 오류 보완
2026-10-22 / SDK 수정

getState 참조 일치
createAgentSessionTools가 getState의 반환 snapshot과 완료 시점의 문서/세션/버전/revision/선택/ready를 대조한다.
변경되면 거절하며 다른 문서의 유효 참조를 발급하지 않는다. 참조에 보관하는 상태는 실제 반환 snapshot이다.
기존의 유효 참조에서 readiness만 내려가면 초기화 오류의 requiredAction을 보존한다.
호스트의 명시 재시도와 제한된 대기 계약은 integration.md에 기록했다. 원래 쓰기는 자동 반복하지 않는다.

저장 영수증 재전달
legacy bridge/toolset commit도 새 재전달 요청의 현재 documentId/sessionId를 확인한다.
같은 세션의 후속 version/revision/ready 변화는 이전 확정 영수증을 무효화하지 않는다.
진행 중 저장 이후 대상이 바뀌더라도 최초 확정 응답은 보존한다. 바뀐 대상에서 새로 요청한 replay는 거절한다.
기존 세션 참조 API와 동일하게 대상 교체를 보호하며 중복 업로드는 하지 않는다.
